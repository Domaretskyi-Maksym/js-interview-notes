Template Syntax ​

Як працюють шаблони ​

Шаблони Vue — валідний HTML. Vue компілює їх в оптимізовані render-функції, а реактивність визначає мінімум компонентів для перерендеру й мінімум змін у DOM.

Можна писати render-функції або JSX напряму, але вони не отримують compile-time оптимізацій, які мають шаблони.

Інтерполяція {{ }} ​

template
<span>Message: {{ msg }}</span>
  • Виводить значення як звичайний текст (HTML екранується).
  • Реактивна: оновлюється при зміні msg.

v-html ​

template
<span v-html="rawHtml"></span>
  • Вставляє сирий HTML як innerHTML. Біндинги Vue всередині ігноруються.
  • Не можна збирати шаблони з частин через v-html: Vue не рядковий шаблонізатор, для повторного використання є компоненти.
  • XSS-ризик: лише для довіреного контенту, ніколи для даних від користувача.

v-bind (атрибути) ​

Mustache не працює в атрибутах, тож потрібен v-bind:

template
<div v-bind:id="dynamicId"></div>
<div :id="dynamicId"></div>   <!-- скорочення -->
<div :id></div>               <!-- те саме, що :id="id" (Vue 3.4+) -->
  • null або undefined видаляє атрибут.

Boolean-атрибути ​

template
<button :disabled="isButtonDisabled">Button</button>
  • truthy або '' → атрибут є (як disabled="").
  • Інші falsy (false, 0, null...) → атрибут прибирається.

Кілька атрибутів одразу ​

js
const objectOfAttrs = { id: 'container', class: 'wrapper' }
template
<div v-bind="objectOfAttrs"></div>

JS-вирази в шаблоні ​

Працюють в інтерполяції та у значеннях директив:

template
{{ ok ? 'YES' : 'NO' }}
<div :id="`list-${id}`"></div>
  • Лише один вираз. Перевірка: чи можна поставити його після return.
  • Інструкції (var a = 1) та if не працюють. Замість if використовуй тернарний оператор.

Виклик функцій ​

template
<time :title="toTitleDate(date)">{{ formatDate(date) }}</time>

Функція викликається при кожному перерендері, тому в ній не повинно бути побічних ефектів (зміни даних, async-запитів).

Обмежені глобальні змінні ​

Вирази працюють у пісочниці: доступний лише allowlist (Math, Date тощо). Властивості, які ти сам додав у window, недоступні. Додати свої глобальні змінні можна через app.config.globalProperties.

Директиви ​

Атрибути з префіксом v-. Значення — один JS-вираз (винятки: v-for, v-on, v-slot). Коли значення змінюється, директива реактивно оновлює DOM.

template
<p v-if="seen">Now you see me</p>

Аргументи ​

Аргумент іде після ::

template
<a v-bind:href="url"></a>   <!-- :href -->
<a v-on:click="doSomething"></a>   <!-- @click -->

Динамічні аргументи ​

template
<a :[attributeName]="url"></a>
<a @[eventName]="doSomething"></a>
  • Значення має бути рядком або null (null прибирає біндинг). Будь-що інше дає warning.
  • Без пробілів і лапок: :['foo' + bar] не працює, винеси в computed.
  • In-DOM шаблони (прямо в HTML-файлі) браузер переводить у нижній регістр: :[someAttr] стає :[someattr]. В SFC цієї проблеми немає.

Модифікатори ​

Модифікатор пишеться через крапку і змінює спосіб прив'язки:

template
<form @submit.prevent="onSubmit"></form>   <!-- викликає event.preventDefault() -->

Повний синтаксис директиви ​

v-on:submit.prevent="onSubmit"
│    │      │        └─ value (вираз)
│    │      └─ modifier
│    └─ argument
└─ name

name:argument.modifiers="value"
