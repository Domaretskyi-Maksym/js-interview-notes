Class and Style Bindings ​

:class і :style — спеціальні покращення v-bind. Окрім рядка можна передати об'єкт або масив, тож не треба збирати класи й стилі конкатенацією рядків.

:class — об'єкт ​

Ключ потрапляє в список класів, якщо значення truthy.

template
<div
  class="static"
  :class="{ active: isActive, 'text-danger': hasError }"
></div>
<!-- isActive=true, hasError=false → class="static active" -->

:class співіснує зі статичним class — вони зливаються. Якщо hasError стане true, буде "static active text-danger".

Об'єкт не обов'язково інлайн: можна передати змінну або computed, що повертає об'єкт — типовий патерн для складної логіки.

js
const classObject = computed(() => ({
  active: isActive.value && !error.value,
  'text-danger': error.value && error.value.type === 'fatal'
}))
template
<div :class="classObject"></div>

:class — масив ​

template
<div :class="[activeClass, errorClass]"></div>
<div :class="[isActive ? activeClass : '', errorClass]"></div>
<div :class="[{ [activeClass]: isActive }, errorClass]"></div>

Тернарний у масиві — для однієї умови. Якщо умов кілька, зручніше вкласти об'єкт у масив.

:class на компонентах ​

На компоненті з одним коренем class / :class автоматично потрапляють на кореневий елемент і зливаються з його класами (fallthrough attributes).

template
<!-- шаблон MyComponent: <p class="foo bar">Hi!</p> -->
<MyComponent class="baz boo" />
<!-- рендер: <p class="foo bar baz boo">Hi!</p> -->

<MyComponent :class="{ active: isActive }" />
<!-- якщо isActive — <p class="foo bar active">Hi!</p> -->

Якщо коренів кілька, треба явно вказати, куди класти клас, через $attrs.class:

template
<p :class="$attrs.class">Hi!</p>
<span>This is a child component</span>
template
<MyComponent class="baz" />
<!-- <p class="baz">Hi!</p> + <span>...</span> -->

Детальніше — Fallthrough Attributes.

:style ​

Об'єкт відповідає element.style. Рекомендовано camelCase; kebab-case теж працює, але ключ у лапках. Одиниці додавай сам (fontSize + 'px').

template
<div :style="{ color: activeColor, fontSize: fontSize + 'px' }"></div>
<div :style="{ 'font-size': fontSize + 'px' }"></div>

Можна передати об'єкт або computed. :style зливається зі статичним style.

Масив об'єктів стилів зливається на одному елементі (пізніші перекривають попередні):

template
<div :style="[baseStyles, overridingStyles]"></div>

Автопрефікси: якщо властивість потребує vendor prefix, Vue сам підставить підтримуваний варіант для поточного браузера.

Кілька значень: :style="{ display: ['-webkit-box', '-ms-flexbox', 'flex'] }" — рендериться останнє значення з масиву, яке браузер підтримує.

Типові питання ​

Навіщо об'єкт/масив, а не конкатенація рядків? Конкатенація легко ламається (пробіли, умови). :class / :style самі додають і прибирають класи та властивості.

Чи можна одночасно писати class і :class? Так, вони зливаються. Те саме для style і :style.

Що буде з class на компоненті? Один корінь — класи зливаються з класами кореня. Кілька коренів — треба явно вказати елемент через $attrs.class.

Чим об'єктний :class відрізняється від масиву? Об'єкт вмикає/вимикає клас за truthiness. Масив — список класів (рядки, тернарний, або об'єкт усередині).

Як зібрати складну умову для класів? Computed, що повертає об'єкт — типовий і зручний патерн.
