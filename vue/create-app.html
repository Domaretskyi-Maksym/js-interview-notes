createApp, mount, errorHandler ​

createApp() ​

Створює ізольований екземпляр додатку з кореневим компонентом. На відміну від new Vue() у Vue 2, конфіг, плагіни та глобальні компоненти належать лише цьому app, тож кілька додатків на сторінці не впливають один на одного.

js
import { createApp } from 'vue'
import App from './App.vue'

const app = createApp(App)

mount() ​

Рендерить кореневий компонент усередину контейнера (DOM-елемент або селектор). До виклику mount() нічого не рендериться.

  • Викликається останнім, після use, component, directive та config.
  • Повертає екземпляр кореневого компонента, а не app, тому ланцюжок закінчується на ньому.
  • Сам контейнер не є частиною додатку.
js
createApp(App).use(router).mount('#app')

app.config.errorHandler ​

Глобальний обробник необроблених помилок з усіх компонентів: рендер, хуки, обробники подій, watcher'и. Використовують для централізованого логування (наприклад, у Sentry).

js
app.config.errorHandler = (err, instance, info) => {
  console.error(err, info)
}
