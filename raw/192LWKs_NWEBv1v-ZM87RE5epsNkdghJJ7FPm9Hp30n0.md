# Промісифікація (Promisification)

Промісифікація — це класичний "міст" між старим кодом (наприклад, базовими модулями Node.js) та сучасним JavaScript. Ви вже частково робили це, коли обгортали `setTimeout` у `new Promise` у задачі з функцією `delay`\!

Ось два головні питання з цієї теми для вашого файлу "Підготовка до Інтервю":

* **Що таке промісифікація і навіщо вона потрібна?** Це перетворення функції, яка працює на колбеках, у функцію, яка повертає `Promise`. Це роблять для того, щоб старий код можна було зручно використовувати в ланцюжках `.then()` або з сучасним синтаксисом `async/await`.  
* **Яке головне обмеження промісифікації?** Колбек може бути викликаний безліч разів (наприклад, при прослуховуванні кліків по кнопці), але Проміс може змінити свій стан (`resolve` або `reject`) **лише один раз**. Тому промісифікувати можна тільки ті функції, які гарантовано викликають колбек одноразово.

*`// Стара функція (змінювати не можна)`*  
`function getUser(id, callback) {`  
 `setTimeout(() => {`  
   `if (id > 0) callback(null, { id, name: "Іван" });`  
   `else callback(new Error("Невірний ID"));`  
 `}, 1000);`  
`}`

*`// Ваша задача: реалізувати getUserPromise`*  
`function getUserPromise(id) {`  
 `// Ваш код тут...`  
 `return new Promise((resolve, reject) => {`  
   `getUser(id, (err, user) => {`  
     `if (err) {`  
       `reject(err)`  
     `}`

     `resolve(user);`  
   `});`  
 `});`  
`}`

*`// Щоб зовнішній код міг працювати так:`*  
`getUserPromise(1)`  
 `.then(user => console.log(user.name))`  
 `.catch(err => console.log(err.message));`
