# Proxy та Reflect

::: v-pre
## 1\. Proxy (Перехоплювач)

* **Що це:** Обгортка навколо об'єкта, яка дозволяє перехоплювати та змінювати стандартні операції (читання, запис, видалення тощо).  
* **Як працює:** Використовує "пастки" (traps) — методи `get, set, deleteProperty` та інші.  
* **Для чого:** Реактивність (як у Vue 3), валідація даних (заборона мінусового віку), логування змін, створення read-only об'єктів.

## 2\. Reflect (Виконавець оригінальних дій)

* **Що це:** Вбудований об'єкт, що має методи для всіх можливих пасток Proxy.  
* **Для чого:** Щоб виконати дефолтну дію (наприклад, фактично записати чи прочитати значення) всередині пастки Proxy безпечно і без "костилів". Завжди працюють у парі: *Proxy перехопив → Reflect виконав оригінал.*

## 3\. Проблема з `this` та `receiver`

* **У чому проблема:** При успадкуванні (коли дочірній об'єкт успадковує методи/гетери від батька-Proxy) пряме звернення `return target[prop]` всередині пастки `get` **ламає контекст `this`**. Гетер виконується в контексті батька, а не сина.  
* **Рішення:** Передати третій аргумент — **`receiver`** — у метод `Reflect.get(target, prop, receiver)`.  
* **Що таке `receiver`:** Це посилання на початковий об'єкт, до якого реально звернулися (дочірній). `Reflect`використовує його, щоб примусово вказати правильний `this` для гетерів та сетерів.

## Базовий приклад використання

Пастка get повертає значення за замовчуванням, якщо властивості немає, а пастка set перевіряє дані перед записом. Усередині пасток ми викликаємо Reflect.get / Reflect.set, щоб зберегти стандартну поведінку об’єкта.

```js
const user = { name: 'Іван' };

const proxy = new Proxy(user, {
  // get: значення за замовчуванням для відсутніх властивостей
  get(target, prop, receiver) {
    if (!(prop in target)) return 'немає даних';
    return Reflect.get(target, prop, receiver);
  },
  // set: валідація — age має бути числом
  set(target, prop, value, receiver) {
    if (prop === 'age' && typeof value !== 'number') {
      throw new TypeError('age має бути числом');
    }
    return Reflect.set(target, prop, value, receiver);
  }
});

console.log(proxy.name); // 'Іван'
console.log(proxy.city); // 'немає даних'
proxy.age = 30;          // ок
proxy.age = 'тридцять';  // TypeError: age має бути числом
```
